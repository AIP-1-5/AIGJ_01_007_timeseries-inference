# Feature Specification: 과제 5 상태 추정

**Branch**: `002-data-baseline` · **Created**: 2026-10-21

## 완료 조건 (원문 그대로)
- **AC-1**: 사용 여부 추정: 직접 관찰한 시간대 기준 정확도와 F1을 보고한다. '비어있음'인데 '사용중'으로 판단하는 오류율을 따로 보고한다. 단순 규칙보다 좋아야 한다
- **AC-2**: 환기 경보: '곧 환기 필요' 재현율 **85% 이상**, 단순 규칙보다 macro-F1이 높다
- **AC-3**: 혼동 행렬을 보고 가장 많이 헷갈리는 경우를 설명한다

산출물: **D-1** 두 분류기의 성적표와 혼동 행렬 · **D-2** 일정 기반 정답과 직접 관찰의 차이 분석 · **D-3** 가장 많이 틀리는 상황 사례

## 요구사항
- FR-001 사용 여부 정답 = 가정 일정(평일 수업 시간, 공휴일 제외), 실습실. 입력에 일정·시각을 넣지 않는다.
- FR-002 환기 경보 양성 = 현재 < 1000ppm이고 30분 안 ≥ 1000ppm. 이미 넘은 시점은 제외.
- FR-003 MLP 분류기, 불균형 보정(양성 가중치), 임계값은 검증 기간에서 선택.
- FR-004 규칙 비교: 사용 여부 "최근 15분 CO₂ +30ppm", 환기 "현재 CO₂ ≥ 850ppm".

## Assumptions
- **직접 관찰 기록이 없다**(과제 범위를 10/21에 정함, 과거 시간대는 관찰 불가). AC-1의 "직접 관찰 기준"은 충족할 수 없어, 일정 기반 정답으로 평가하고 미충족으로 보고한다. 10/22 교육장에서 몇 시간대를 관찰하면 그 시간대로 다시 잴 수 있다.
