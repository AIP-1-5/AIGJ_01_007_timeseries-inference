# Feature Specification: 과제 3 60분 예측

**Feature Branch**: `002-data-baseline` (과제 3~8을 같은 브랜치에서 빠르게 진행, 2026-10-21 사용자 지시) · **Created**: 2026-10-21 · **Status**: Draft

## 완료 조건 (원문 그대로)

- **AC-1**: 60분 뒤 CO₂ 오차가 '현재값 유지'보다 **30% 이상 작다**
- **AC-2**: 온도 60분 예측이 '현재값 유지'보다 좋다
- **AC-3**: 시험 기간 데이터를 학습이나 모델 선택에 쓰지 않았다

산출물: **D-1** 모델 비교표(기준선 + 학습 모델, 예측 시점별 오차) · **D-2** 공간별 오차 분석과 원인 · **D-3** 일정 정보 포함/제외 비교와 결론

## User Story (P1)

분석자가 과제 2의 공용 전처리 시계열로 60분(5분 × 12칸) 앞 CO₂·온도를 한 번에 예측하는 딥러닝 모델을 학습하고, 과제 2와 **같은 평가 시점**에서 기준선과 비교한다. 일정 정보를 뺀 모델과 비교해 일정의 기여를 숫자로 낸다.

**Acceptance**: ① 시험 기간 60분 CO₂ MAE ≤ 현재값 유지 × 0.7 (공간별, 목표 실습실 45.4·사무실 38.1·회의실 68.0) ② 온도 60분 MAE < 현재값 유지 ③ 학습은 학습 기간, 모델·에폭 선택은 검증 기간만 ④ 평가 시점은 `eval_points.parquet` 그대로.

## Requirements

- **FR-001** 입력: 과거 2시간(24칸)의 CO₂·온도·습도(학습 기간 정규화), 관측 여부, 공간, 시간대·요일, 일정 특성(수업 시간대·공휴일). 일정 특성은 끌 수 있어야 한다(D-3).
- **FR-002** 출력: 60분을 한 번에(12칸 × CO₂·온도). 현재값에서의 **변화량**을 예측한다.
- **FR-003** 모델: GRU 1종(기본 트랙 A).
- **FR-004** 평가는 과제 2 평가 시점에서, 같은 거리·같은 시점으로 기준선과 비교. 모든 평가 시점에 예측이 있어야 한다(입력 결측은 채움 + 결측 표시).
- **FR-005** 결과표에 측정 조건(데이터 기간, 실데이터, 시험 기간, 전력 모드, 커밋, 시드).

## Assumptions

- 일정 자료 없음 → 일정 특성 = 가정 일정(평일 09:00~12:00·13:00~18:00 수업, 공휴일 제외). 공휴일은 미리 알 수 있는 정보다.
- 실데이터만(합성 없음). 학습은 보드 B GPU(가능하면) 또는 CPU.
