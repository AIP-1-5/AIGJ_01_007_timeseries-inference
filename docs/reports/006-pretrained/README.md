# 과제 6 사전학습 모델 비교: 결과와 채택 의견

| 측정 조건 | 값 |
|---|---|
| 데이터 | 실데이터, 시험 기간 2026-09-01~10-20, 60분 뒤 CO₂. 과제 2 평가 시점에서 공간마다 800개 무작위 표본(시드 0) — 세 방법이 **같은 시점** |
| 사전학습 모델 | `amazon/chronos-bolt-small`(파라미터 4,770만), 추가 학습 없음, CO₂ 과거 512칸(약 42시간)만 입력, CPU float32 |
| 직접 학습 모델 | 과제 3 GRU(일정 포함, v1) |
| 보드 | 보드 B MAXN_SUPER, CPU. **측정 중 과제 3 재학습이 CPU를 함께 사용**(지연이 실제보다 클 수 있음) |
| 재현 | `python -m tsmodel pretrained` · `pretrained_results.json` |

| 공간 | 현재값 유지 MAE | GRU MAE | Chronos MAE | Chronos 10~90% 구간 적중률 |
|---|---|---|---|---|
| 실습실 | 55.8 | **43.9** | 45.2 | 78.6% |
| 사무실 | 54.7 | **40.8** | 50.9 | 75.3% |
| 회의실 | 99.0 | **74.3** | 95.0 | 78.3% |

| 비용 | GRU | Chronos-Bolt-small |
|---|---|---|
| 1회 추론(배치 1) | 수 ms(과제 7) | 평균 **544ms**, p95 667ms(워밍업 5회 뒤 85회) |
| 메모리 | 수 MB | 최대 RSS 1,232MB(데이터 포함, 모델 로드 전 912MB → **약 +320MB**) |

## 판정

| 기준 | 판정 |
|---|---|
| AC-1 세 방법을 같은 시점에서 비교 | 통과(공간마다 같은 800개 시점) |
| AC-2 정확도·구간 적중률·추론 시간·메모리로 근거 제시 | 통과(위 두 표) |

## 채택 의견

**지금 서비스에는 채택하지 않는다.** 우리 데이터로 학습한 GRU가 세 공간 모두 더 정확하고(특히 사무실 −10ppm, 회의실 −21ppm), 수백 배 빠르고 메모리도 훨씬 적다. Chronos는 학습 없이도 실습실에서 GRU에 근접(45.2 vs 43.9)했고 예측 구간 적중률이 75~79%로 이상(80%)에 가깝다. 그래서 **새 공간을 처음 붙일 때(학습 데이터가 쌓이기 전 몇 주)의 임시 예측기**나 **예측 구간이 필요한 경우**에는 쓸 만하다. 같은 보드에 로컬 LLM이 함께 올라가야 하므로 +320MB와 0.5초짜리 CPU 점유는 상시 매분 서비스에 부담이다.

## 생각해 볼 점

- **차이 중 얼마가 시간대·요일·온습도 때문인가**: Chronos는 CO₂ 과거 값만 본다. GRU(일정 제외)와 GRU(일정 포함)의 차이(과제 3, 실습실 약 5ppm)가 일정 정보 몫이고, 나머지 차이는 시간대·온습도·우리 데이터 학습 몫이다. 실습실처럼 하루 패턴이 뚜렷한 곳은 42시간 과거만 봐도 Chronos가 패턴을 따라가지만, 사무실·회의실처럼 불규칙한 곳은 차이가 크다.
- **과거 길이**: 이번에는 512칸(42시간)만 썼다. 어제 같은 시각을 포함하는 최소 길이가 24시간 이상이라 이 정도가 필요하다(다른 길이 비교는 하지 않음).
- **로컬 LLM과 메모리 예산**: 보드 8GB를 CPU·GPU가 함께 쓴다. LLM이 수 GB를 차지하면 Chronos +320MB도 아깝다. GRU는 무시할 수준이다.
