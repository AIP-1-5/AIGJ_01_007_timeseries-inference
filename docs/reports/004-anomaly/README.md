## 못 잡는 고장과 이유 (AC-3)

- **모델(오토인코더)이 못 잡는 것: 값 고정·영점 틀어짐·냉방/환기 정지.** 1시간 창 안에서 값이 "정상 범위 안"에 있으면 재구성이 잘 된다. 정상 값에서 멈춘 센서는 한 시간 동안 조용한 방과 구별되지 않고, 몇 시간에 걸친 영점 상승·온도 상승은 1시간 창에서는 완만한 정상 변화처럼 보인다. 헛경보를 하루 1회 안으로 맞추려면 임계값이 높아져 결국 큰 튄 값만 남는다.
- **규칙이 못 잡는 것: 환기 정지(5/12), 값 고정 일부(9/12).** 환기 정지는 상승 폭을 1.8배로 키우지만, 원래 상승이 작은 날(인원이 적은 날)은 키워도 평소 붐비는 날 수준을 넘지 않는다. 시간대별 상한·상승 폭 규칙은 "평소 붐비는 날"을 기준으로 하기 때문이다. 값 고정은 온도를 수업 시간에만 보게 해(밤에는 원래 온도가 1시간 동안 그대로일 수 있음) 그 밖의 시간대에 심은 고정을 놓친다.
- **헛경보가 남는 이유**: 실데이터에 원래 있던 드문 날(늦은 퇴실, 휴일 사용, 2026-09 과정 사이 변화)도 "평소와 다름"이라 규칙에 걸리고, 우리는 그것을 모두 헛경보로 셌다(정답이 없는 실데이터의 한계, 보수적 계산).

## 운영 제안

- 경보 등급을 나눈다: **튄 값·값 고정·냉방 정지**(정밀도 높음)는 즉시 시설 담당에게, **환기·영점**은 하루 요약으로 데이터 담당에게.
- 영점 틀어짐은 새벽 기준값 비교가 가장 확실하므로(11/12) 매일 아침 1회 점검 보고로 충분하다.
- 헛경보를 줄이려면 공간별 임계값(회의실은 인원 변동이 커서 더 느슨하게)과 일정 정보(휴일·늦은 수업)를 규칙에 넣는다.

## 생각해 볼 점

- **정상 범위에서 멈춘 센서를 모델이 못 알아채는 이유**: 모델은 "본 적 있는 모양인가"를 묻는데, 평평한 1시간은 밤·빈 방에서 늘 보는 모양이다. "시간이 지나도 전혀 안 변함"을 직접 묻는 규칙이 필요하다.
- **빈 방의 환기 정지**: 사람이 없으면 CO₂가 오르지 않아 데이터로는 보이지 않는다. 사람이 없으면 환기가 필요 없으므로 탐지할 필요도 낮다. 다음 사용 때 상승 폭으로 잡으면 된다.
- **정답 없는 실데이터에서 확인하는 법**: 이번처럼 실데이터에 고장을 심어 재 보고, 실제 경보는 사람이 확인한 결과(맞음/틀림)를 쌓아 정밀도를 추적한다. 실제 고장 1건(`2590`, 2026-07-04~06의 65,535ppm)은 범위 규칙으로 정제 단계에서 이미 잡힌다.
