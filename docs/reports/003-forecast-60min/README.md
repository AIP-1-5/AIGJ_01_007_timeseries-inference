# 과제 3 60분 예측: 결과와 판정

| 측정 조건 | 값 |
|---|---|
| 데이터 | 실데이터(InfluxDB `iot-bucket` 스냅샷), 과제 2 전처리 |
| 기간(KST) | 학습 2025-09-01~2026-06-30 · 검증 2026-07-01~08-31(조기 종료·모델 선택) · **시험 2026-09-01~10-20**(마지막에 한 번) |
| 모델 | GRU 1층(은닉 64), 입력 2시간(24칸), 60분을 한 번에 출력(5분 × 12칸, 변화량), 시드 0. 일정 포함/제외 두 개 |
| 학습 | 보드 B CPU(10/21, R9 이전). 에폭당 54초(일정 포함)·121초(일정 제외), 조기 종료 17·15 에폭 |
| 평가 | 과제 2 평가 시점(`eval_points.parquet`) 그대로. 기준선과 같은 시점·같은 정답 |
| 표 | [comparison.md](comparison.md)(전체 비교표), `training_history.json` |

## 판정

| 기준 | 결과 (시험 60분) | 판정 |
|---|---|---|
| CO₂ 오차가 현재값 유지보다 **30% 이상** 작다 | 실습실 46.4 vs 64.9 (**−29%**), 사무실 42.3 vs 54.4 (−22%), 회의실 77.6 vs 97.2 (−20%) | **미통과** (실습실 1%p 모자람) |
| 온도 60분이 현재값 유지보다 좋다 | 실습실 0.131 vs 0.153, 사무실 0.088 vs 0.098, 회의실 0.191 vs 0.214℃ | 통과 |
| 시험 기간을 학습·선택에 안 씀 | 조기 종료·모델 선택은 검증 기간 60분 CO₂ MAE로만 | 통과 |

검증 기간에서는 실습실이 −51%(46.5 vs 95.5)로 기준을 넘었다. 시험 기간에 못 넘은 이유는 모델이 나빠져서가 아니다. **현재값 유지가 시험 기간에 훨씬 잘 맞았다**(95.5 → 64.9). 모델 오차는 두 기간 모두 46ppm대로 같았다. 검증 7~8월에는 방학·과정 전환으로 하루 흐름이 들쭉날쭉해 현재값 유지가 많이 틀렸을 것으로 추정한다(확인 필요).

## 공간별·시간대별 오차와 원인 (시험, 평일, 60분 CO₂ MAE ppm)

| 시간대 | 실습실 GRU / 현재값 | 사무실 GRU / 현재값 | 회의실 GRU / 현재값 |
|---|---|---|---|
| 00~06시 | 5~11 / 16~33 | 5~8 / 8~25 | 10~13 / 13~28 |
| **08시** | **186 / 250** | 57 / 118 | 125 / 145 |
| 09시 | 129 / 196 | 99 / 131 | **321 / 372** |
| 10~17시 | 80~130 / 74~161 | 100~126 / 85~132 | 146~301 / 150~309 |
| 18시 | 74 / 167 | 92 / 153 | 101 / 231 |
| 20~23시 | 11~34 / 43~62 | 13~27 / 33~56 | 14~25 / 31~72 |
| 주말 전체 | 10.8 / 14.0 | 7.0 / 9.1 | 12.2 / 14.6 |

1. **모델이 이긴 곳은 "규칙적인 변화"다.** 밤에 CO₂가 천천히 빠지는 것(00~06시 오차 1/3), 퇴실 뒤 떨어지는 것(18시 74 vs 167), 등원 때 오르는 것(실습실 08시 186 vs 250)을 배웠다. 현재값 유지는 "그대로"라고 해서 이 변화를 통째로 틀린다.
2. **모델이 거의 못 이긴 곳은 낮 시간(10~17시)이다.** 사람이 들고 나는 것은 2시간 과거와 시계만으로는 알 수 없다. 사무실 12~13시는 GRU가 현재값 유지보다 오히려 나빴다(100 vs 85, 106 vs 97). 점심 이동이 날마다 달라서 "평균적인 점심"을 예측하면 오히려 틀린다.
3. **회의실이 가장 어렵다(−20%).** 회의는 예약제라 시각이 날마다 다르다. 가정 일정(수업 09~18시)은 회의실을 설명하지 못한다. 오차의 43%가 09·13·14·15시에 몰렸다. 센서도 10분 간격이라 5분 칸의 약 절반이 앞 값으로 채운 칸이다.
4. **실습실 오차의 21%는 08~09시 두 시간에 있다.** 수업 시작이 공휴일·휴강에 따라 바뀌고, 사람이 오기 시작하는 시각도 날마다 흔들린다(추정).

## 일정 정보 포함/제외 비교 (시험 60분 CO₂)

| 공간 | 일정 제외 | 일정 포함 | 차이 |
|---|---|---|---|
| 실습실 | 51.7 | 46.4 | **−5.3ppm** |
| 사무실 | 42.4 | 42.3 | −0.1ppm |
| 회의실 | 78.7 | 77.6 | −1.1ppm |

**결론: 일정 정보를 넣으면 실습실 60분 예측 오차가 5.3ppm(10%) 줄어든다. 사무실·회의실은 거의 그대로다.** 넣은 일정이 "수업" 일정이라 수업을 하는 실습실에만 맞는다. 사무실(근무)과 회의실(예약)에는 그 공간의 일정이 필요하다. 일정 자료(시간표, 회의실 예약)는 받지 못해 CO₂ 곡선에서 추정한 가정 일정을 썼다(decisions R8).

## 더 해 볼 것 (맥에서, 우선순위 순)

1. **회의실 예약 자료**를 받으면 회의실 입력에 "예약 중" 특성을 넣는다. 기대 효과가 가장 크다(오차의 43%가 회의 시간대).
2. **"어제 같은 시각 값" 입력(v2)은 효과가 없었다**(검증 66.61 → 66.59ppm). 시험 평가는 하지 않았다. 버린다.
3. 손실을 60분 칸에 가중치를 더 주거나, 입력을 2시간 → 4시간으로 늘려 시험한다(검증 기간으로 고른다).
