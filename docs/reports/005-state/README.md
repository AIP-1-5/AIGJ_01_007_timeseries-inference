## 가장 많이 틀리는 상황

- **사용 여부: 오후 수업 중 "비어 있음"으로 판단**(15~17시 오류율 33~38%). 사람이 오래 머물러 CO₂가 높은 채 평평해지면 "변화" 특성이 0에 가까워져 빈 방처럼 보인다. 또 가정 일정이 실제와 다른 날(일찍 끝난 수업, 휴강)은 정답 자체가 틀린다 — 직접 관찰이 필요한 이유.
- **빈 방 오판(358건)**: 사람이 나간 직후 CO₂가 아직 높고 천천히 떨어지는 동안(퇴실 뒤 절반까지 55분, 과제 2) "사용 중"으로 남는다.
- **환기 경보 헛경보(2,543건, 정밀도 19%)**: 1,000ppm 바로 아래에서 오르다 멈추는 날이 많다. 재현율 85%를 지키려면 이런 날까지 경보를 낸다.

## 일정 기반 정답과 직접 관찰 (D-2)

직접 관찰 기록이 없어 비교하지 못했다(과제 범위를 10/21에 정해 과거 시간대는 관찰할 수 없음). 대신 데이터에서 본 어긋남: 공휴일 대체 사용(12/25, 3/2, 5/5, 8/17), 늦은 퇴실 22일(과제 2) — 일정 기반 정답이 틀리는 대표 경우다. 10/22 교육장에서 몇 시간대를 `docs/observations.csv`에 적으면 같은 코드로 관찰 기준 성적을 낼 수 있다.

## 생각해 볼 점

- **막 나간 직후·막 들어온 직후**: 나간 직후는 CO₂가 높아 사용 중으로, 막 들어온 직후는 아직 오르기 전이라 비어 있음으로 오판된다. CO₂가 사람보다 늦게 반응하기 때문이다(10~55분).
- **적은 인원의 큰 강의실**: 사람 한 명당 CO₂ 상승이 공간 부피에 반비례해 작아져 구별이 어렵다. 큰 공간일수록 문턱을 낮추거나 온도·습도 변화를 더 본다.
- **재현율 vs 정밀도**: 환기는 놓치면 건강·집중도 문제라 재현율 우선이지만, 정밀도 19%면 경보 5번 중 4번이 헛경보라 운영자가 무시하게 된다. 경보 대신 "곧 1,000ppm" 대시보드 표시 + 실제 초과 직전에만 알림처럼 등급을 나눈다.
- **과제 3 예측으로 판단하는 것과 비교**: 예측은 "얼마나"를 주고 분류기는 "넘을지"를 바로 준다. 분류기는 문턱 근처를 직접 배워 재현율을 맞추기 쉽고, 예측은 다른 문턱(800ppm 등)에도 다시 쓸 수 있다. 서비스(과제 8)는 둘 다 낸다.
