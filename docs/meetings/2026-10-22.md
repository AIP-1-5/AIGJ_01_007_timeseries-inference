# 2026-10-22 강사 미팅 준비 (나영준, 007)

순서: 진행 보고 1분 → 꼭 받아야 할 답 3개 → 알려 드릴 것 → 시간 남으면 추가 질문.
답을 받으면 아래 "답" 칸에 적어 두면 Claude가 spec·설정·roadmap에 반영한다.

## 1. 진행 보고 (1분)

> 과제 1은 수집기를 보드 B에 systemd 서비스로 올려 어제 16시부터 돌고 있습니다. 강제 종료해도 5초 만에 재시작했고 데이터 손실이 없었습니다. 형식 변경 대응은 설정 7줄로 코드 수정 없이 했습니다. 브로커 재시작·재부팅 시험은 오늘 오전에 하고, 24시간 커버율 보고서는 오늘 16시 이후에 나옵니다.
>
> 과제 2는 InfluxDB 1년치(2025-09 ~ 2026-10)로 끝냈습니다. 세 기준선 중 **현재값 유지가 모든 공간·거리에서 가장 강했고**, 시험 기간 60분 CO₂ 오차가 실습실 65, 사무실 54, 회의실 97ppm입니다. 다만 현재값 유지는 **9시 수업 시작, 점심, 퇴실 때 크게 틀립니다**(실습실 9시 323ppm). 과제 3~8은 마감 안에 하지 못하지만, 과제 3의 목표선(실습실 45, 사무실 38, 회의실 68ppm)과 공용 전처리를 남겼습니다.

## 3. 알려 드릴 것 (사실 보고)

- 게이트웨이 `…dccc`의 시계가 약 **5분 빠릅니다**. 저희는 네트워크 서버 시각(nsTime)을 기준으로 저장해 영향은 없습니다.
- 사무실 AM103(`…1175`) **배터리 1%**입니다.
- 실습실 EM500-CO2(`…2590`)가 **2026-07-04~06에 65,535ppm을 1,069번** 냈습니다(센서 고장으로 보고 제거).
- 실습실 EM300-TH(`…1523`)는 **10분 간격**이고 온도가 다른 센서보다 **약 5℃ 낮습니다**(18.5℃ vs 23.8℃). 창가나 외벽 쪽에 있는지 궁금합니다.
- InfluxDB에서 **사무실 2026-02 한 달**, **2026-05 전 공간 절반**이 비어 있습니다.
