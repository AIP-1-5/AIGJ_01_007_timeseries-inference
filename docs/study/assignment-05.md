# 과제 5에서 배운 것: 상태 추정

결과: [docs/reports/005-state](../reports/005-state/README.md) · 코드: `tsmodel/state.py`

## 무엇을 했나

센서값만으로 실습실 사용 여부를 맞히는 분류기와, "30분 안에 1,000ppm 초과"를 미리 알리는 환기 경보 분류기를 만들었다. 환기 경보는 재현율 89%로 통과, 사용 여부는 직접 관찰 기록이 없어 미충족.

## 개념 → 왜 필요한가

| 개념 | 비유 | 정의 | 왜 필요한가 | 백엔드로 치면 |
|---|---|---|---|---|
| 분류 | 스팸/정상 메일 나누기 | 입력을 정해진 종류 중 하나로 판단 | "사용 중인가", "곧 넘나"는 예/아니오 질문 | 사기 거래 탐지 |
| 정답 정의 | 시험 채점 기준 | 무엇을 양성으로 볼지 정함 | 이미 넘은 시점을 넣으면 "지금 높다"만 배워 미리 알리는 능력이 없어진다 | 비즈니스 규칙 명세 |
| 정답 누수 | 답안지를 문제에 섞기 | 정답을 만든 정보(일정)를 입력에 넣음 | 모델이 센서가 아니라 시계를 보고 외운다 → 일정과 다른 실제 사용을 못 잡음 | 테스트에 기대값 하드코딩 |
| 불균형 | 1,000명 중 환자 19명 | 양성이 2% 안팎 | 전부 음성이라 해도 정확도 98% → 정확도 무의미 | 장애는 드물어서 가용성 99%가 쉽게 나옴 |
| 재현율·정밀도·F1 | 그물로 고기 잡기: 놓친 것 vs 쓰레기 | 재현율 = 양성 중 잡은 비율, 정밀도 = 경보 중 진짜 비율, F1 = 둘의 조화평균 | 무엇을 놓치면 더 아픈지에 따라 기준을 고른다 | 알림의 미탐 vs 오탐 |
| 혼동 행렬 | 맞춤/틀림 4칸 표 | 정답×예측 2×2 표 | 어디서 틀리는지(빈 방 오판 등) 바로 보인다 | 알림 결과 분류표 |

## 알아둘 결과

- 사용 여부는 **오후 수업 중 "비어 있음" 오판**이 가장 많다. CO₂가 높게 평평해지면 변화가 없어 빈 방처럼 보인다.
- 환기 경보는 재현율을 지키는 대신 정밀도 19%. 현장에서는 경보 등급을 나눠야 한다.

## 말로 설명할 수 있어야 할 것 3개

1. 사용 여부 입력에 일정·시각을 넣으면 안 되는 이유.
2. 환기 경보 정답에서 이미 1,000ppm을 넘은 시점을 빼는 이유.
3. 정확도 98%가 왜 아무 의미가 없는지, 대신 무엇을 봤는지.

## 스스로 확인할 질문 2개

1. 내일 직접 관찰한 시간대로 재면 일정 기반 정답보다 성적이 오를까 내릴까?
2. 정밀도를 40%까지 올리려면 재현율을 얼마나 포기해야 할까? (임계값을 바꿔 보기)
