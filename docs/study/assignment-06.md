# 과제 6에서 배운 것: 사전학습 모델 비교

결과: [docs/reports/006-pretrained](../reports/006-pretrained/README.md) · 코드: `tsmodel/pretrained.py`

## 무엇을 했나

남이 수많은 시계열로 미리 학습해 둔 Chronos-Bolt를 추가 학습 없이 우리 CO₂에 써 보고, 기준선·GRU와 같은 시점에서 정확도·예측 구간·속도·메모리를 비교했다. 결론: 정확도·비용 모두 GRU가 낫다. 새 공간 초기용으로만 가치가 있다.

## 개념 → 왜 필요한가

| 개념 | 비유 | 정의 | 왜 필요한가 | 백엔드로 치면 |
|---|---|---|---|---|
| 파운데이션 모델 | 여러 회사 경력직 | 다양한 데이터로 미리 학습해 바로 쓰는 범용 모델 | 우리 데이터가 쌓이기 전에도 예측할 수 있다 | SaaS를 바로 붙여 쓰기 vs 직접 개발 |
| 제로샷 | 처음 보는 문제를 바로 풀기 | 추가 학습 없이 사용 | 새 공간을 붙일 때 학습 기간이 필요 없다 | 설정 없이 동작하는 기본값 |
| 분위수 예측·예측 구간 | 일기예보 "강수 확률 80%" | 값 하나가 아니라 10%~90% 범위를 냄 | 얼마나 확신하는지 알아야 경보·제어를 결정한다 | SLA의 p50/p90 |
| 구간 적중률 | 범위 예보가 맞은 비율 | 실제 값이 10~90% 범위 안에 든 비율, 이상 80% | 구간이 너무 좁으면 과신, 넓으면 쓸모없음 | 예측 신뢰 구간 검증 |
| 비용(지연·메모리) | 연비 | 1회 추론 시간과 메모리 | 같은 보드에 LLM과 함께 올라간다 | 서버 리소스 예산 |

## 알아둘 결과

- 실습실은 Chronos가 GRU에 거의 근접(45.2 vs 43.9), 사무실·회의실은 크게 뒤짐. **패턴이 뚜렷한 곳만 범용 모델이 따라간다.**
- 구간 적중률 75~79%: 범용 모델의 구간이 거의 맞게 보정되어 있다.

## 말로 설명할 수 있어야 할 것 3개

1. 같은 시점 비교를 어떻게 보장했는지(평가 시점에서 같은 표본).
2. 채택하지 않은 근거 네 가지(정확도·구간·지연·메모리).
3. 범용 모델이 쓸모 있는 상황(새 공간 초기, 구간이 필요할 때).
